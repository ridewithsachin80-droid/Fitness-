## 1. Every colour is a token now

Sprint 0 tokenised the theme but left 47 one-off hex colours in the JSX — fourteen different
greys, six golds, seven near-black backgrounds, a leftover purple gradient. 206 occurrences
across 23 files are now their nearest token *by role*: the greys collapse to six
(`white · bright · mid · mute · lo · ghost`), the golds to four, the backgrounds to two, the
purple AI gradient to gold. This is a deliberate, small visual consolidation — the point of
Sprint 12 — not pixel-identical like Sprint 0 was.

The contract is now absolute: **no hex colour inside a class anywhere**, enforced by the test,
with one named exception — WhatsApp green on the WhatsApp button, which is not ours to
rename. Mutation-checked.

## 2. The chat's store is a store

`useAIChat` (open / focus / composer / apply state) lived inside `AIChatLog.jsx`. Every screen
that only needed to *open* the chat — the nav orb, Today's read, onboarding, the sheets'
banners — imported the whole component to get it, and `UI.jsx → AIChatLog → UI.jsx` was a
cycle waiting to bite.

Now: `store/aiChatStore.js`. `AIChatLog` re-exports it, so nothing that imported the old way
breaks; the seven consumers that only need the store import the store. The composer's layout
constants and two small atoms moved to `components/chat/ChatAtoms.jsx`. And the chat's private
copy of the protocol derivation — a mirror of `lib/day/protocol.js` — is gone; it uses the one
the rest of the app uses.

Every moved identifier was checked to resolve in the built bundle (a bundler passes an
undefined name silently; the check does not).
